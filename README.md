# EzyFlow bridge for Odoo

The EzyFlow bridge is an Odoo module, `ezyflow_bridge`, that adds the fields and
behaviours the EzyFlow connector needs on your Odoo database and nothing else.
It works on Odoo 19 and Odoo 20 from one tree: the same folder installs on both
series. It is licensed under LGPL-3.

This repository is generated by the EzyFlow connector's release process. It
takes no pull requests and has no issue tracker. For any question, write to
support@ezytail.com.

## Three numbers to know

- **Installed**: the version of the module on your database. Odoo shows it in
  Apps, on the EzyFlow bridge row.
- **Oldest accepted**: not stated for this release. The connector refuses an older bridge.
- **Built with**: bridge 3.10.0 (EzyFlow connector v0.12.0).
  The connector was tested against this bridge.
- **Latest**: the newest release of this repository.

The two figures above are those of this release. The current oldest accepted
version and built-with version are shown in the EzyFlow portal, and the
EzyFlow team can tell you: a later connector release can raise the oldest
accepted version without a new bridge.

A bridge newer than the one the connector was built with is safe. Upgrade the
bridge first, then the connector.

## Install

Pick one route. In all three, Odoo must find the `ezyflow_bridge` folder on its
addons path, then you install EzyFlow bridge from Apps.

**a. Zip from the Releases page.** Download `ezyflow_bridge-<version>.zip`
from the Releases page, check it against `SHA256SUMS`, and unzip it into a
folder of your addons path. The folder `ezyflow_bridge` appears there.

**b. Git clone or pin.** Clone this repository, or pin it at a tag such as
`v3.10.0`, and put the repository root on your addons path (the folder
that contains `ezyflow_bridge`). The `19.0` and `20.0` branches both follow the
latest release.

**c. Odoo.sh.** Add this repository as a submodule of your Odoo.sh project, on
the branch named after your series: `19.0` or `20.0`.

Then update the apps list and install EzyFlow bridge in Apps.

## Upgrade

1. Back up the database.
2. Replace the `ezyflow_bridge` folder with the one of the new release (or move
   the pinned tag).
3. Run `odoo -d <database> -u ezyflow_bridge --stop-after-init`, or press
   Upgrade on the module in Apps.
4. Restart Odoo, so the changed Python code is loaded.

The release notes of each release say whether the upgrade is required or
optional, whether it carries a migration, and what to check afterwards. Read
them before you upgrade.

## Help inside Odoo

The module explains itself in Odoo: open Apps, then EzyFlow bridge, for the
help page. The same page is reachable from the Help block on the EzyFlow
settings page.
